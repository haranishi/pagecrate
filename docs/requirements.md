# 製品の要件（要約）

PageCrate は、公開ページの素材を、出典を失わずに手早く持ち帰るための道具です。登録なしで誰でも使え、運営者は利用者のデータを残しません。はじめて来た人が3分で全体をつかめるよう、要件を短くまとめます。

## 誰の、何のためか

対象は、素材を集めたい初見の人（制作者・学生・デザイナーなど）です。専門用語に詳しくなく、スマホ（幅390px）でも開き、登録を求められると離れる人を想定しています。成功の目安は二つあります。初見の人が1分以内にデモでZIPを手にすること、そして実際のURLでも迷わず保存まで着くことです。

## すること

1. 公開された単一ページのURLから、画像（img・picture・srcset・CSS背景・poster・video の source）と通常の動画の候補を集める
2. 種類・名前・最小幅で絞り込み、選択中の件数と表示中の件数を分けて示す
3. 選んだ素材を変換せずにZIPへまとめ、取得日時・出典ドメイン・素材ごとの成否を記した manifest を入れる
4. 外部へ接続しないデモで、同じ流れを体験させる
5. 混雑・回数制限・停止・1日の上限・期限切れのそれぞれで、起きたこと・次の行動・再開の目安を示す
6. 画面に共有の手段（X・LINE・端末の共有・リンクのコピー）を置く

## しないこと

- 複数ページの巡回。対象のサイトへの負荷と運営の費用が読めなくなる
- ログイン・有料の壁・CAPTCHA・DRM の回避。権利者が掛けた制限を破ることになる
- HLS・DASH・blob の動画の保存。分割された配信の結合が要り、この道具の範囲を超える。検出して理由を示すだけにする
- アカウント・課金・管理画面。管理画面を作ると運営者の認証が要り、ログインなしの方針と衝突する
- 再利用してよいかの判定と、外部のAIへの素材の送信
- 運営者の設備での結果の保管。「何も残さない」約束と両立しない

## 利用者に約束すること

- ログインを求めない。氏名・メールアドレス・パスワード・外部アカウントの連携も、どの機能でも求めない
- 入力したURL・取得した素材・候補の一覧を、処理のあと運営者の設備に保存しない。接続元は回数制限のために縮めた値として短い時間だけ使い、取得の内容とは結び付けず、記録にも残さない
- 使う前にプライバシーポリシーを見せる。「読みました」の確認は端末の中だけに持ち、版が変わったら次の開始の前に確かめ直す
- 候補の一覧は30分で使えなくなり、過ぎたら取り直しを案内する
- URL欄の近くに、「取得できても再利用の許諾ではない。権利者の許諾と対象サイトの規約を確かめる」旨を常に出す
- 規約・ポリシー・Cookie の説明を実際の動作と一致させ、運営者の名称と窓口を載せる。名称と窓口が決まるまでは一般に公開しない

## 運営者のための仕組み

公開すると、悪用と費用の暴走が最大の危険になります。そこで上限で止まる作りにしました。接続元ごとの回数制限、解析の前のボット確認、1日の描画回数の上限、運営者による停止、取得を断るドメインの指定、同時に処理する数の制限です。どれかの仕組みが答えられないときは、取得を始めずに閉じます。内部のアドレスを取得する設定は、公開された経路に置きません。操作の手順は [運営の手順](operations.md) にあります。

## 制限

| 項目 | 上限 |
|---|---|
| 1回の解析 | 候補200件・40秒 |
| 保存 | 1件25MiB、ZIP1つにつき合計100MiB・50件 |
| プレビュー | 画像1枚2MiB、同時に2件。外部のSVGは表示しない |
| 候補の一覧の有効期限 | 30分 |

保存のときは形式と中身の先頭を確かめ、申告と違う素材は保存せずに失敗として示します。

## 画面の品質

幅390・768・1440pxで横にはみ出さないこと、キーボードだけで主な操作を終えられること、アクセシビリティの自動検査（WCAG 2.1 AA）で違反が0件であることを条件にしています。

## 公開の条件

運営者の名称・窓口とライセンスが決まり、[公開前の点検](release-hygiene.md) と [権利・規約の確認](rights-and-terms.md) の記録がそろうまで、一般向けには公開しません。いまは全ページに検索エンジンへ載せない指定（noindex）が付いています。外すかどうかは運営者が決めます（未定）。
