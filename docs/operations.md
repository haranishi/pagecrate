# 運営の手順

管理画面はありません。作ると運営者の認証が要り、ログインなしの方針と衝突するからです。運営者は、Worker の秘密値と Cloudflare のダッシュボードで操作します。秘密値の名前と初回の設定は [Cloudflare への配置](deployment.md) にあります。

秘密値を変えるコマンドには、配置先を取り違えないよう `CLOUDFLARE_ACCOUNT_ID=<your-account-id>` を付けます。`wrangler secret put` は新しい版をその場で配置しますが、全拠点で効くまでの時間は未測定です。

## 止める：`PAGECRATE_PAUSED`

`npx wrangler secret put PAGECRATE_PAUSED` で `1` を入れると、実サイトの解析・プレビュー・ZIP が止まり、画面に停止中と出ます。説明のページとデモは使えます。再開するときは `0`（か `false`）を入れます。

**止めない値は、`0` と `false` だけです。** 未設定や空の値、`yes`・`on`・全角の `１` などの書き間違いは、すべて停止として読みます。書き間違いで実サイトの取得が開かないようにするためです。

止める手段は、この停止の値と、配置の取り下げです。どちらも、効くまでの時間は測っていません。チケット鍵の入れ替え（下の節）は、発行済みのチケット（プレビューと ZIP）を使えなくするだけで、新しい解析は止めません。

## デモだけ公開する：確認が済むまで `PAGECRATE_PAUSED` は `1`

公開サイトは、弁護士と Cloudflare への確認（[権利・規約・個人情報の確認結果](rights-and-terms.md)）が済むまで、`PAGECRATE_PAUSED` に `1` を入れて出します。他人のサイトには触れず、自作の素材だけを使うデモと説明のページが動きます。

画面は、開いた時点の設定で表示します。`/app` の URL 欄の上には「実サイトの取得は、いまお休み中です。デモなら、自作の素材で同じ流れを試せます。」と「デモを試す」のボタンが常に出ます。トップの紹介の補足と締めくくりの注記、`/demo` の注記も、停止中の文に替わります。URL を入れて「素材を見つける」を押すと、確認画面もボット確認も出さずに、状態の帯へ停止中の案内と「デモを試す」を出します。このとき Cloudflare の Turnstile とは通信しません。開いたままの画面は、読み込み直すまで前の設定のままです。

`wrangler.jsonc` の `secrets.required` の7件は、配置のたびにすべて要ります。デモだけの間は、Turnstile の2件（`PAGECRATE_TURNSTILE_SITEKEY`・`PAGECRATE_TURNSTILE_SECRET`）に使われない値を入れておいて構いません。停止中は画面もサーバーもこの2件を使わないからです。`PAGECRATE_TURNSTILE_SITEKEY` を鍵の形に合わない短い値（例：`unused`）にしておくと、停止を外す順番を誤っても、画面はボット確認を読み込まずに「準備できていません」と出します。

配置のたびに、公開の直後に、停止が効いていることを確かめます。`curl -s -w '\n%{http_code}\n' -X POST -H 'Origin: <公開の origin>' -H 'content-type: application/json' -d '{"url":"https://example.com/"}' <公開の origin>/api/scan` が `503` と `"code":"PAUSED"` を返せば、停止しています。ほかの応答（ボット確認の失敗など）が返ったら停止が効いていないので、すぐに停止の値を直すか、配置を取り下げます。

再開は次の順に進めます。鍵が使われない値のまま `0` を入れると、実サイトの取得は準備できていない扱いになるか、ボット確認で失敗します。

1. Turnstile の2件を本物の鍵に入れ替える
2. 本番とは別名の Worker で、この文書の最後の節「公開の後に、実キーで確かめること」の項目をすべて終える
3. `PAGECRATE_PAUSED` に `0` を入れる

## 1日の上限：`PAGECRATE_DAILY_RENDER_CAP`

1日に描画する（解析する）回数の上限です。数えるのは解析だけです。プレビューとZIPは数えません。日付は UTC で区切るので、日本時間の午前9時に回数が戻ります。上限に達すると、画面に「本日の分は終了」と再開の目安を出し、デモは使えます。`0` や数字でない値を入れると、実サイトの取得は閉じます。数えた記録は7日分だけ残し、新しい日の最初の描画のときに古い分を消します（描画の無い日が続くと、その間は残ります）。上限の値は、Browser Run の料金と無料枠（Free は1日10分）を見て決めます。

## 取得を断る：`PAGECRATE_BLOCKED_HOSTS`

カンマ区切りで並べたドメインは、そのドメインと下のサブドメインがすべて対象です（先頭の `*.` や `.` も同じ意味。IP は完全一致）。確かめるのは、解析の入口、転送のたび、チケットを使う時点（プレビューとZIP）の三か所です。足せば、そのドメインの発行済みのチケットも使えなくなります。ホスト名として読めない項目が1つでもあると、すべてのホストを断り、実サイトの取得が閉じます。権利者から取得を止めるよう求められたら、まずここに足します。

## チケット鍵の入れ替え：`PAGECRATE_TICKET_SECRET`

入れ替えると、発行済みのチケットがすべて無効になります。利用者は一覧を取り直すことになります。デモも同じです。回数制限の鍵も同じ鍵から作っているので、回数の数えもそこからやり直しになります。チケットは接続元に結び付けていないため、期限の30分のあいだは別の端末からも使えます。使い回しによる悪用が止まらないときの最後の手段です。

## 予算の通知

Browser Run と Workers の Paid には、自動の支出上限がありません。請求の通知をダッシュボードで設定してください。1日の上限が止めるのは描画だけです。プレビュー・ZIP・デモの要求には、全体の上限がありません。全利用者を合わせた総量を止める手段は、停止と配置の取り下げに限られます（鍵の入れ替えは、発行済みのチケットだけを無効にします）。

## 回数制限の性質と穴

回数制限は、接続元（IPv6 は /64、IPv4 はそのまま）を日替わりの鍵で縮めた値ごとに数えます。上限の回数は `wrangler.jsonc` で決め、期間は10秒か60秒から選びます。数えは Cloudflare の拠点ごとの近似で、別の拠点からの要求とは合算されません。厳密な上限ではありません。Cloudflare は IP を回数制限の鍵にすることを勧めていません。学校や携帯回線のように接続元を共有する人どうしで回数を分け合うことになるからです。アカウントの無いこの製品では、それを承知で採っています。

デモの解析は Worker の外へ出ないため、接続元ごとの回数制限がありません。連打は、そのまま Worker の要求数と CPU になります（Free は1日10万要求まで）。Cloudflare の WAF の回数制限ルールはゾーン単位の機能で、workers.dev では使えない見込みです（公式文書に明記は無く、二次情報による。未確認）。それまでは使用量と請求の通知で見張り、必要になったら独自ドメインへ移して WAF を使います。

## 悪用が見えたときの順番

1. 停止するか、対象のドメインを拒否に足す（速く、元に戻せる）
2. 止まらなければ、チケット鍵を入れ替える（発行済みのチケットがすべて無効になる）
3. それでも止まらなければ、配置を取り下げる
4. 起きたことと取った手を記録する。URL・チケット・接続元は記録に書かない

調べるときは `npx wrangler tail` を使います。保存はされません。ただし画面には、要求の URL（チケットから素材の URL を読める）とヘッダーがそのまま出ます。出力を保存したり、どこかに貼ったりせず、調べ終えたら止めてください。

## 公開の後に、実キーで確かめること

手元のプレビューと E2E では確かめられない項目です。本番とは別名の Worker で先に確かめ、本番でも確かめ直します。

- 回数制限が超えた要求を断ること、1日の上限で描画が止まること、停止で取得が止まること
- 実キーの Turnstile が、サーバーの検査（公開 origin のホスト名と action `scan`）を通ること。`Referrer-Policy: no-referrer` のもとでもウィジェットが動くこと
- どのページから作業画面へ移っても、解析を始めたときにコンソールへ CSP の違反が出ないこと
- 自分で公開した試験用のページ（ホスト名は公開の前に消す）を、解析して保存できること。そのとき Turnstile が端末に置く Cookie と保存を観測し、Cookie のページの表と照らし合わせること
- 同じ試験用のページに `http://127.0.0.1/`・`http://[::1]/`・内部向けの名前・引くたびに答えが変わる試験用のドメイン（DNS rebinding の試験用に公開されているもの）の画像を並べ、どれも取得されないこと
- 秘密値を変えてから効くまでの時間

実サイトでの試験は、自分で用意したページか許諾のあるページだけで行い、第三者のサイトに負荷をかけないでください。
