確認日：2026-11-01。[権利・規約・個人情報の確認結果](rights-and-terms.md) の続きです。このリポジトリ自体のライセンスは MIT です（運営者の決定。2026-11-01）。`LICENSE` は、公開用スナップショットの道具（`npm run snapshot`）が書き出します。著作権者の欄は、`src/lib/operator-info.ts` の運営者の名称です。決まっていないと未確定の印になり、公開の関門が止めます。

## 結論

- 本番の依存は MIT・Apache-2.0・ISC・BSD・BlueOak などで、MIT で公開することを妨げるものは見当たりません
- 第三者の表記が特に要るのは、閲覧者のブラウザーへ配る JavaScript（Next.js や React など）です。公開リポジトリに `node_modules` は入りません。リポジトリ自体が配る第三者のコードは、複製して入れた点検の道具（`scripts/hygiene.mjs`。複製元は同じ運営者の別リポジトリの MIT のコードで、元の表示を冒頭に残し、`THIRD_PARTY_NOTICES.md` にも載せます）だけです
- 同梱の画像・動画・アイコンは、このリポジトリのコードで描いたものか、アプリの画面と ffmpeg の試験パターンを録ったものです。書体は OS のものだけです

## 第三者の表記の方針（1は `npm run snapshot` が実行する。2〜4は未了）

1. `package-lock.json` の開発用でない全項目について、名前・版・ライセンス・著作権の行・ライセンスの全文を `node_modules` から機械的に集め、`THIRD_PARTY_NOTICES.md` を作る。Apache-2.0 は NOTICE も写す。同じ本文は1つにまとめ、全文が見つからないものは隠さず「全文なし」と一覧に残す
2. 実際に配る物を分ける。閲覧者のブラウザーへ配る JavaScript と、Cloudflare で動く Worker の bundle に入るパッケージを、ビルドの出力から割り出す。配らない物（任意のネイティブ部品、配置の道具）も、配らない理由を添えて一覧に残す
3. ブラウザーへ配る JavaScript に著作権の表示が残らないなら、サイトのフッターから表記へリンクするかを決める
4. `@cloudflare/playwright`（本番で使う、Apache-2.0）は、パッケージに LICENSE と NOTICE のファイルが無い。元になった Playwright の表記を含めるかを決める
5. ほかのプロジェクトから複製する道具は、複製元の著作権とライセンスの表示を残す

## 同梱の素材の出どころ

| 素材 | 出どころ | 確かめたこと |
|---|---|---|
| アプリのマークとアイコン（`src/app/icon.svg`・`src/components/icons.tsx`） | コードに手で書いた単純な線のパス | icons.tsx の5種（check・search・lock・external・warning）は、Feather と Lucide の同じ用途の図と座標が一致しない |
| トップの図と、共有用の画像 `public/og.png` | 図は CSS で描いたもの。og.png はその図から文字を消し、`scripts/make-og-image.mjs` で撮ったもの | PNG に文字やメタデータの領域（tEXt・eXIf など）が無い |
| デモの画像（SVG） | `src/lib/demo.ts` がコードで生成する | 書体は名前の指定だけ（Helvetica・sans-serif）で、書体のファイルは無い |
| デモの動画と `fixtures/motion-study.webm` | ffmpeg の試験パターン（testsrc2）から作った2秒の動画。デモはこれを埋め込んで使う | 1秒目のコマが testsrc2 の模様と一致し、付帯情報はエンコーダーの名前だけ。作った日と人の記録はリポジトリに無い |
| 紹介動画・ポスター・字幕（`public/tour/`） | アプリのデモの画面を `scripts/record-tour.mjs` で録ったもの | 付帯情報はエンコーダーの名前だけ。ポスターの WebP に EXIF・XMP の領域は無い。画面の文字は、録画した端末の OS の書体で描かれている |
| 書体 | OS の書体だけ（`src/app/globals.css` の指定） | Web フォントの読み込みと書体のファイルは無い |
